# 大一课程学习与复习资料

整理以大一课程为主的学习与复习资料，方便查找课件、复习提纲、习题、往年试卷和实习配套资料，也欢迎一起补充与纠错。

本仓库涉及地图学、普通测量、高等数学、线性代数、C/C++、数据结构与程序设计、计算机与编程原理、军事理论、思政等内容；同时保留了当前目录中的部分计算机网络资料。

> 本页根据现有目录及子目录名称整理，未逐一核对资料正文。目录归类沿用整理时的结构，适用课程、年级及考试范围请以资料实际内容和当学期教学要求为准。

## 使用建议

1. 按上方课程导航进入目录，按需下载。需要保存整个仓库时，可使用 GitHub 的 **Code → Download ZIP**。
2. 结合当学期课程大纲和教材梳理知识点，再用习题与往年试卷查漏补缺。
3. 资料中的答案、总结和考试范围仅供参考，遇到疑问请结合教材、课堂讲解及推导核对。
4. 编程与实习作业建议先独立完成，再对照参考内容理解方法。

## 参与补充

欢迎通过 **Issue** 反馈资料错误和目录问题，或通过 **Pull Request** 补充笔记、勘误与有权公开分享的学习资料。

- 优先放入对应课程目录，避免重复上传。
- 文件名建议包含课程、内容和年份，例如：`地图学_期末复习提纲_2026.md`。
- 补充资料时尽量注明来源、适用年份及版本；修订解答时说明思路和依据。
- 提交前移除姓名、学号、联系方式等个人信息，以及无关缓存、依赖和编译产物。
